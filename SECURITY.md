# Security

This package contains local instructions, example files, and local checks. It has no hosted service and asks for no account credentials.

## Report a problem

Do not open a public issue for a secret, private-data leak, or exploitable vulnerability. Email `hello@lemonbrand.io` with:

- the affected file or version;
- what you expected;
- what happened;
- the smallest safe reproduction you can share.

We will acknowledge the report within five business days.

## Safe use

- Review brand files before sharing them with any AI host.
- Keep source artwork unchanged and save generated work separately.
- Confirm that you may use every reference.
- Review outputs before publishing them.
- Treat legal and trademark clearance as a separate decision.
