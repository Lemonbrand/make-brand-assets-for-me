# Make A Brand Asset Set

Follow `SHOW → PLAN → MAKE → CHECK → SAVE`.

Read `references/five-steps.md`, `references/ask-the-user.md`, and `references/check-the-look.md`.

## What to do

1. Read the brand recipe and approved asset list.
2. List the ideas in order and give each one a plain job.
3. Remove ideas that do not need their own image. Do not force a fixed number.
4. Make a short plan table with order, name, job, visual idea, required parts, source labels, format, and shared rules.
5. When the user did not already approve the full set, use the structured ask-user function to approve the table before generating several images. Use one short chat question when the function is unavailable.
6. Make each approved member as a separate file.
7. Use object identity and arrangement to show differences. Do not rely on words or color alone.
8. Check every asset alone against three anchors.
9. Check the complete set for order, missing ideas, duplicates, scale, padding, and family fit.
10. Save separate PNGs, one contact sheet, one set record, and one row per file in the set list.

## Finish with

- the approved set table;
- every PNG path;
- contact-sheet path;
- set-record path;
- plain pass, draft, or needs-review results.
