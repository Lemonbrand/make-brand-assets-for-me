# Five Steps

Use the same path every time:

1. **Show:** Read the user's approved brand examples and rules.
2. **Plan:** State the job, surface, files to reuse, parts to change, and parts that must be new.
3. **Make:** Choose the smallest useful action: reuse, adapt, combine, generate, or animate.
4. **Check:** Compare the whole result and every important part with three approved examples at thumbnail and full size.
5. **Save:** Save the output and a plain record of the brief, sources, prompt, checks, file path, size, and result.

Do not skip the plan because the image looks simple.
