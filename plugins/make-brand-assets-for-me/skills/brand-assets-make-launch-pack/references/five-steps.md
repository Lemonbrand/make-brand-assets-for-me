# Five Steps

1. **Show:** Read the approved brand examples, recipe, source facts, launch page, and CTA.
2. **Plan:** Turn the chosen pack mode into a placement table. State what is reused and what changes by shape.
3. **Make:** Build the shared system, then render each placement, carousel, copy block, alt text, and tracked link.
4. **Check:** Compare against three approved visual anchors, inspect every size, and run the launch-pack checklist.
5. **Save:** Save the files, proof sheet, receipts, source facts, copy, and public campaign manifest together.

Do not skip the placement table because the launch feels simple. A coordinated pack fails when every file is individually attractive but the family does not tell one clear story.
