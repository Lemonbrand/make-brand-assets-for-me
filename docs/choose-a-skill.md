# Choose A Skill

| You need | Use |
| --- | --- |
| Rules from examples | Set Up My Brand |
| One object | Make One Brand Asset |
| One picture with several parts | Make A Brand Scene |
| Several separate matching files | Make A Brand Asset Set |
| Motion added to approved art | Make A Brand Asset Move |
| A complete multi-channel launch family | Make My Launch Pack |

If the request changes from one row to another, switch skills. Do not stretch one skill into every job.

Use **Make My Launch Pack** when several surfaces must tell one story. Use the other skills when the user needs one object, one scene, one framework family, or one motion file.
