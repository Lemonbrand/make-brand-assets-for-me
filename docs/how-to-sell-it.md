# How To Share It

Do not sell the package. Let the package show how you work.

## The simple path

1. Share the public GitHub repository.
2. Show one asset made with a real brand you have permission to discuss.
3. Explain the five-step process in plain language.
4. Link to the free 60-minute Inbox Audit when the person's bigger problem is operational work, not visual production.

## What the package proves

- Lemonbrand can turn judgment into a repeatable workflow.
- The workflow asks for human decisions at the right moments.
- The output is checked and recorded, not merely generated.
- The method can move between agent hosts.

That is the marketing asset. The user's own brand assets remain their deliverable.
