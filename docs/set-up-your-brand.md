# Set Up Your Brand

1. Gather examples you may use.
2. Mark them “use as-is,” “change from this,” “look only,” or “do not use.”
3. Run **Set Up My Brand**.
4. Answer only the questions that change the result.
5. Approve the short summary.

The result is a brand recipe called `brand-rules.yaml` and an approved shelf called `asset-list.csv`.
